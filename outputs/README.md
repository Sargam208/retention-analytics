# Outputs

Everything in this folder is written by `python run_all.py` and read by the dashboard (`app/app.py`). It is committed so the dashboard can be deployed without Spark or the raw data. Re-running the pipeline overwrites it.

`REPORT.md` has every headline number in one place. It is written by `src/06_make_report.py`.

| File | Written by | Contents |
|---|---|---|
| `etl_report.json` | 01_spark_etl | Row counts after each cleaning step, date range, dataset totals |
| `segmentation_k_selection.csv` | 02_segmentation | Inertia and silhouette for k = 2–8 |
| `segmentation_metrics.json` | 02_segmentation | Chosen k, silhouette, PCA variance kept |
| `pca_loadings.csv` | 02_segmentation | Feature loadings on each principal component |
| `customers_segmented.csv` | 02_segmentation | One row per customer with PCA coordinates and segment name |
| `segment_profile.csv` | 02_segmentation | Size, revenue share, and median RFM per segment |
| `churn_metrics.csv` | 03_churn_model | CV and out-of-time test metrics for each model and the baseline |
| `churn_curves.csv` | 03_churn_model | ROC and precision-recall curve points |
| `churn_lift_table.csv` | 03_churn_model | Churn rate, lift, and cumulative capture by score decile |
| `churn_feature_importance.csv` | 03_churn_model | Permutation importance per model |
| `churn_scores_current.csv` | 03_churn_model | Churn probability and risk band for currently active customers |
| `churn_summary.json` | 03_churn_model | Best model, its test metrics, the recency baseline, top features, sample sizes |
| `ab_rates.csv`, `ab_results.csv` | 04_ab_test | Retention by group; z-test, bootstrap CI, Holm p-value, MDE |
| `ab_bootstrap_samples.csv` | 04_ab_test | Bootstrap draws of the retention difference |
| `ab_summary.json` | 04_ab_test | SRM check, guardrail metric, decision |
| `uplift_arm_ates.csv` | 05_uplift | Average treatment effect per e-mail arm and outcome |
| `uplift_metrics.csv` | 05_uplift | Qini coefficient and uplift@k per learner |
| `uplift_qini_curves.csv`, `uplift_deciles.csv` | 05_uplift | Qini curve points; observed uplift by predicted decile |
| `uplift_summary.json` | 05_uplift | Test-set ATE and headline targeting result |
| `figures/*.png` | steps 2–5 | Static charts used in the main README |

`models/` (fitted model files) is not committed. It is regenerated by step 3.
